# Local Audio Library v0.5.0-beta.1（验证中草案）

> 状态：F4 已通过，正在执行 Beta 发布验证。本文件仍是草案，三平台 release
> checklist 全部通过前不得视为正式发布说明。

该候选版本已完成本地数据安全、桌面端发布链路和一批日常整理工作流加固。

## 主要变化

- 增加数据库 schema 版本检查和迁移前完整备份；备份失败时停止升级。
- 统一 Python、前端、Cargo、Tauri 和应用内版本号。
- 增加 Playlist 重命名与删除，并明确删除 Playlist 不会删除音频。
- 支持非破坏性移除媒体库目录，保留音频记录、标签、Playlist 和 Transcript。
- 支持标签合并，并同步维护音频关联和全文搜索索引。
- 支持显式多选，并批量添加 / 移除标签、加入 Playlist、收藏 / 取消收藏。
- 支持逐段修订 Transcript 并保留时间轴；全文替换仍会明确确认清除旧分段。
- 播放队列支持列表/详情加入、下一首、持久恢复、拖拽和键盘排序。
- 默认安装包改为 lite，faster-whisper 运行时通过校验后的可选 companion 下载。
- 加强本地 API token、日志脱敏、Tauri 后端端口选择和退出清理。

## 升级说明

- 正式升级前请保留一份 `~/.local_audio_library/` 的额外副本。
- 应用需要迁移旧数据库时，会在 `backups/` 下生成经过完整性检查的备份。
- 核心数据与音频文件保持解耦；移除目录、Playlist 或应用本身都不应删除原始音频。
- 本地转写需先安装可选 Whisper companion；模型首次使用时另行下载并缓存。

## 已知限制

- 仍需完成 Linux、Windows 和 macOS 的安装、升级与卸载 smoke test。
- Transcript 不提供富文本、手工时间戳修改或自动重新对齐。
- Whisper companion 和模型缓存需首次联网获取；完全离线前必须预先安装/缓存。
- 完整备份恢复向导、自动章节、语义搜索和本地问答不在本版本范围内。

完整发布门槛见 [`../release-checklist.md`](../release-checklist.md)。
