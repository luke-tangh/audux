# Audux v1.0.0

Audux 1.0.0 是首个公开稳定版本，将此前内部候选中的本地音频资料库、有据 Agent、可恢复
整理流程与发布安全边界冻结为 v1 契约。应用数据库保持 schema v6，与
`0.9.0-beta.1` 候选数据一致，不因稳定版升级改写数据库。

## 主要能力

- 本地资料库扫描、播放、metadata、Tag、手动/智能 Playlist、保存视图和批量整理。
- 不可变 Transcript revision、Segment 时间锚点、章节、质量 issue 与 TXT/JSON/SRT 导出。
- SQLite FTS5 检索、后端强制 scope、可验证引用，以及需要 before/after 预览和一次性批准
  的低风险 Agent 写操作。
- 本地 Whisper companion、外部 OpenAI-compatible ASR/LLM，以及 Provider 失败时不影响
  核心离线能力的降级路径。
- 只读 MCP stdio Server、带校验的数据库快照、当前格式归档、dry-run 导入、脱敏诊断包和
  Tauri 签名 updater。

## 稳定版契约

- 数据库 schema v6；可移植归档格式 v1。
- MCP 首选 `2026-07-28`，并保留三个已记录的旧 initialize 版本回退。
- Linux x86_64、Windows 10/11 x86_64、macOS 13+ Intel/Apple Silicon 为 v1.0 发布目标。
- 完整兼容、弃用、Provider、降级和回滚约定见[兼容性契约](../compatibility.md)。

## 从内部候选升级

升级前先在“设置 → 维护”创建并验证数据库快照。`0.9.0-beta.1` 与 `1.0.0` 均使用 schema
v6，稳定版会直接打开现有数据；其他 schema、无 marker 或损坏的数据库不会被修改。若升级
失败，保留原数据目录并用匹配版本恢复快照，不要删除数据库、WAL 或整个 `~/.audux/`。

## 发布限制

Windows/macOS 安装包当前没有操作系统级代码签名或公证，首次安装可能显示未知发布者提示；
应用内更新仍经过 Tauri updater 签名验证。归档不包含原始音频，导入后需要重新关联。
不同 ASR/LLM 模型的准确率和 tool calling 能力存在差异，embedding 仍为可选能力，FTS5 是
稳定离线基线。

完整安装、恢复、Provider、MCP、长期运行和三平台验收步骤见[发布检查清单](../release-checklist.md)。
