> Status: internal beta history. This candidate never created a public GitHub Release; the first
> public release was reserved for v1.0.

This candidate hardened local data safety, desktop packaging, and routine organization workflows.

## Highlights

- Added schema checks that reject mismatched prerelease databases without modification.
- Unified Python, frontend, Cargo, Tauri, and in-app versions.
- Added playlist rename/delete, non-destructive library-root removal, tag merge, explicit
  multi-selection, and batch tag/playlist/favorite operations.
- Added segment-preserving transcript correction; full replacement explicitly discards old segments.
- Added persistent playback queues with next, drag, and keyboard ordering.
- Made the default package lite and moved faster-whisper into a validated optional companion.
- Hardened the local API token, log redaction, dynamic Tauri port selection, and process cleanup.
- Added manual snapshots, integrity checks, restore preflight, restart switching, and rollback.

## Upgrade notes

Keep an extra copy of `~/.audux/`. Prerelease schemas were not migrated automatically; use a
matching build to create and validate a snapshot. Removing roots, playlists, or the application does
not remove original audio. Local ASR requires the optional companion and separately cached model.

## Known limitations

Three-platform install/uninstall smoke tests remained outstanding. Transcripts had no rich text,
manual timestamp editing, or automatic realignment. Fully offline use required preinstalled
companion/model data. Scheduled/cloud backup, automatic chapters, semantic search, and local Q&A
were outside scope.
