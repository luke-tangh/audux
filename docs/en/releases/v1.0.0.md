# Audux v1.0.0

[Release notes](README.md) · [English documentation home](../README.md) ·
[简体中文](../../zh-CN/releases/v1.0.0.md)

Audux 1.0.0 is the first public stable release. It freezes the local audio library, evidence-backed
agents, recoverable organization workflow, and release-security boundary from the internal
candidates into a v1 contract. The database remains schema v6, identical to `0.9.0-beta.1`, and is
not rewritten merely for the stable version.

## Highlights

- Local library scanning, playback, metadata, tags, manual/smart playlists, saved views, and batch
  organization.
- Immutable transcript revisions, segment time anchors, chapters, quality issues, and TXT/JSON/SRT
  exports.
- SQLite FTS5, backend-enforced scope, validated citations, and low-risk agent writes requiring a
  before/after preview and one-time approval.
- Local Whisper companion, external OpenAI-compatible ASR/LLM, and degradation that preserves core
  offline capabilities after provider failure.
- Read-only MCP stdio, verified database snapshots, current-format archives with dry-run import,
  redacted diagnostics, and a signed Tauri updater.

## Stable contracts

- Database schema v6; portable archive format v1.
- Preferred MCP `2026-07-28`, with three documented legacy initialize fallbacks.
- Linux x86_64, Windows 10/11 x86_64, and macOS 14+ Apple Silicon release targets; Intel Mac is not
  supported.
- See the [compatibility contract](../reference/compatibility.md) for providers, degradation,
  deprecation, and rollback.

## Upgrade from the internal candidate

Create and validate a database snapshot under Settings > Maintenance first. Both
`0.9.0-beta.1` and `1.0.0` use schema v6, so stable Audux opens the data directly. Other schemas,
missing markers, and corruption are rejected without modification. On failure, preserve the data
directory and restore with a matching version; do not delete the database, WAL, or `~/.audux/`.

## Release limitations

Windows and macOS installers lack operating-system code signing/notarization and may show an
unknown-publisher warning; in-app updates still validate Tauri signatures. Archives exclude
original audio and require relinking after import. Model accuracy and tool calling vary; embeddings
remain optional and FTS5 is the stable offline baseline.

See the [release checklist](../contributing/release-checklist.md) for installation, recovery,
provider, MCP, long-running, and three-platform validation.
