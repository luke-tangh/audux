# Audux v0.9.0-beta.1 (internal candidate)

[Release notes](README.md) · [English documentation home](../README.md) ·
[简体中文](../../zh-CN/releases/v0.9.0-beta.1.md)

v0.9 added controlled low-risk writes, external read-only MCP, portable archives, and redacted
diagnostics on top of cited Q&A and organization runs. It remained an internal candidate.

## Highlights

- Agents could propose in-app metadata, accepted tags, manual-playlist membership, saved views, and
  queued transcription. The backend froze targets and before/after values and fingerprinted the
  plan; the desktop approved that exact plan once.
- Execution rechecked source state. Target drift, scope expansion, fingerprint mismatch, and replay
  were rejected. Plans ran atomically and retained proposal/approval/execution/failure audit.
- Added sidecar `--mcp` stdio mode exposing only read Tool Registry operations with structured output
  and citation IDs. `AUDUX_MCP_AUDIO_IDS=1,2` further restricted process scope.
- Added versioned, SHA-256-verified current-format archives. Credentials, tokens, media-root paths,
  and audio were excluded. Import required dry-run, current schema, an empty library, and a
  transaction; imported audio awaited relinking.
- Added allowlisted diagnostics containing version, platform, safe configuration, task summary, and
  integrity only—no transcripts, logs, keys, tokens, or absolute paths.
- Advanced schema to v6. ASR/AI, interactive agent, and organization runs retained separate
  single-worker queues. Agent and organization inputs were bounded to 24,000 and 12,000 transcript
  characters per target; external-ASR chunk concurrency was capped at four.

## MCP startup

```bash
cd backend
uv run --locked python run.py --mcp

audux-backend-<target-triple> --mcp
```

stdout is JSON-RPC only; errors disclose no local paths, provider configuration, or credentials.
Validation covered operation replay/staleness, real MCP `2026-07-28` discovery/list/call plus legacy
initialize, absent write schemas, archive dry-run/import/FTS rebuild/redaction, and three-platform
Rust plus internal builds.
