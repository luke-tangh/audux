# Audux v0.8.0-beta.1 (internal candidate)

[Release notes](README.md) · [English documentation home](../README.md) ·
[简体中文](../../zh-CN/releases/v0.8.0-beta.1.md)

v0.8 completed a transcription > validation > evidence-backed proposal > human approval >
transactional write > revalidation loop. It remained an internal candidate.

## Highlights

- Added persistent organization runs that freeze target audio IDs and source revisions across
  `preflight`, `transcribe`, `validate`, `review`, `enrich`, `apply`, `reindex`, and `verify`.
- Added a workbench for all supported scopes with per-stage counts, failures, pending approvals, and
  provider-bound transcript character counts.
- Stored source revision, supporting segments, rationale, confidence, and audit events for
  correction, tag, description, and chapter proposals; corrections show character diffs.
- Added accept, edit-and-accept, reject, skip, and evidence playback. Writes are triggered by
  category with impact previews; there is no preview-bypassing “accept all.”
- Applied corrections as new immutable revisions together with text/FTS and accepted organization
  data in one transaction. Revision conflicts or index failures leave no partial state.
- Marked unapplied proposals stale after current-revision changes and revalidated resolved,
  persistent, and new issues deterministically.
- Kept diagnostic summaries bounded and free of keys, local token, paths, or full transcripts.
- Aggregated runs in the activity center; restart marks executing runs interrupted, and restore
  preflight blocks active or pending-review runs.

Schema advanced to prerelease v5 without old-schema migration. Verification covered frozen scope,
stale proposals, deduplication, transactional mixed-category apply, cancellation, failure,
interruption, and restore blocking.

Original-file metadata writes, unsupported open-ended writes, arbitrary file/network access, and
external MCP writes remained excluded.
