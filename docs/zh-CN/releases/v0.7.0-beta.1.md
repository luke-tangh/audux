# Audux v0.7.0-beta.1（内部候选）

[发布记录](README.md) · [中文文档首页](../README.md)

> 状态：内部 Beta，不创建对应的公开 GitHub Release；首次公开发布仍统一为 v1.0。

## 主要变化

- 新增当前 Transcript revision 的 Segment 级 FTS5 索引；结果统一包含 audio、revision、
  Segment、时间范围、命中字段、上下文与分数。
- 新增统一 scope resolver，支持整个资料库、当前音频、显式选择集、Playlist、保存视图、
  Tag 和媒体库目录。模型无法通过工具参数扩大 scope。
- 新增本地 Agent 会话、消息、run、step、tool call 和 citation 数据模型；Agent 使用独立
  worker，不与 ASR / AI 音频任务共用队列。
- 第一批只读工具包含范围搜索、音频详情、Transcript Segment、质量 issue、Tag、Playlist
  清单和范围统计；不支持 tool calling 的 Provider 不会执行 Agent run。
- Agent 面板支持范围选择、会话重命名/删除/导出、持久化轮询、取消、工具错误展示，以及
  点击引用跳转到对应音频时间点。
- 所有 citation 在响应时重新校验 run scope、当前 revision、Segment 与时间边界；revision
  变化、Transcript 删除或音频删除后不会继续展示陈旧引用。
- embedding 保持可选。当前候选以 FTS 为质量基线，请求 hybrid 且未配置 embedding 时明确
  返回 `embedding_not_configured` 并继续使用 FTS，不影响关键词搜索或 Transcript 浏览。
- 当前预发布数据库 schema 更新为 v4；仍按 v1.0 前策略拒绝其他 schema，不自动迁移。

## 评测与验证

- `backend/evals/v0_7/` 固定中英混合查询、Segment 期望与 Prompt Injection/范围泄漏样例，
  记录 Recall@5、首个结果延迟、引用覆盖率、无证据回答率和范围泄漏数。
- 自动化测试覆盖 scope 冻结、FTS 回退、Agent 取消、引用播放，以及 revision 变化后的引用
  失效。
- 本机隔离演练的 1 万条音频基线：首个 FTS 结果 98 ms、Agent 取消 91 ms、普通播放记录
  查询 0.8 ms、Python 峰值分配约 92 MB、SQLite（含 WAL）约 11.1 MB。该数字用于回归比较，
  不是对所有硬件的性能承诺。

## 升级说明

- v0.6 数据库不会被 v0.7 自动修改。请保留旧构建与快照，在独立数据目录创建 v0.7 当前
  schema 后重新导入资料。
- 正式验证前保留 `~/.audux/` 的额外副本；不要用测试数据覆盖日常资料库。

## 已知边界

- 本地 embedding 模型尚未选型；当前统一检索稳定使用 FTS5。
- Agent 只读，不执行 Tag、Playlist、metadata、Transcript 或文件系统写操作。
- 整理 run、勘误审批和 Tag/描述建议属于 v0.8。
- 三平台安装包和真实音频的人工交互性演练仍需按 release checklist 在目标 OS 执行。
