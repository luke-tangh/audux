# Audux v0.6.0-beta.1（内部候选）

[发布记录](README.md) · [中文文档首页](../README.md) · [English](../../en/releases/v0.6.0-beta.1.md) · 简体中文

> 状态：内部 Beta，不创建对应的公开 GitHub Release；首次公开发布仍统一为 v1.0。

## 主要变化

- Transcript 改为不可变 revision：重新转写、逐段勘误和全文替换都会形成新修订，旧内容
  保留历史可读性，但不会继续作为当前搜索或 Agent 证据。
- 每个 revision 保存 Provider、模型、语言、脱敏任务配置、术语表版本、质量指标与父修订。
- Segment 成为绑定 revision 的稳定可播放证据锚点；JSON 导出包含 revision、章节和 issue。
- 增加手工章节的创建、重命名/边界调整、合并和删除；新 revision 不继承旧章节。
- 增加确定性 Transcript 校验与结构化 issue，覆盖越界、倒序、重叠、空段、全文不一致、
  疑似语言异常和低置信度；issue 关闭必须保留原因。
- 定义 ASR、LLM、Embedding Provider 契约；LLM 连接测试探测结构化输出、tool calling 和
  流式 tool calling，不支持 tool calling 的模型不能进入工具执行路径。
- 增加 Pydantic Tool Registry、后端注入 scope/权限与两个只读工具；模型参数不能提供
  根路径、endpoint、token 或 API Key。
- 增加无隐私的中英混合固定评测 manifest 和可重复合成 WAV 生成器。
- 当前预发布数据库 schema 更新为 v3；仍按 v1.0 前策略拒绝其他 schema，不自动迁移。

## 升级说明

- v0.5 数据库不会被 v0.6 自动修改。请使用匹配的旧构建导出或保留快照，并在独立数据
  目录验证 v0.6。
- 正式验证前保留 `~/.audux/` 的额外副本；不要用测试数据覆盖日常资料库。

## 已知边界

- 自动章节、统一 Segment 检索和带引用的只读 Agent 属于 v0.7。
- Agent 勘误审批、Tag/描述建议和完整 Run 状态机属于 v0.8。
- 三平台安装包仍需按 release checklist 对该候选逐平台做 clean-install smoke test。

## 本候选验证记录

- 临时数据库演练已覆盖 100 条音频与 600 个 revision：在前 500 个 revision 时创建已
  校验快照 → 新建 100 个 revision → 安排恢复并生成恢复前安全快照 → 模拟重启切换 →
  校验恢复为 500 个历史 revision 和 100 个唯一当前 revision。
- 该演练和自动化测试都使用临时数据目录，不读取或修改 `~/.audux/` 用户资料。
