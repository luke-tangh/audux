# 用户指南

[返回中文文档首页](../README.md)

本分区面向使用 Audux、配置本地或远程 Provider，以及排查日常问题的用户。

建议按以下顺序阅读：

1. [安装与快速上手](getting-started.md)：选择运行方式、启动应用并建立第一个资料库。
2. [AI、ASR 与 MCP 配置](configuration.md)：配置 Whisper、外部 ASR、LLM、长音频切片和
   只读 MCP Server。
3. [数据、备份与安全](data-and-security.md)：了解数据目录、备份恢复、归档、本地 API 和
   隐私边界。
4. [故障排查](troubleshooting.md)：处理 Token、后端、Provider、搜索索引和任务状态问题。

涉及稳定格式、Provider/MCP 公共契约或版本回滚时，以
[v1 稳定性与兼容性契约](../reference/compatibility.md)为准。
