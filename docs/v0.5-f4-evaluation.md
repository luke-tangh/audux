# v0.5 F4 收口评估

评估日期：2026-08-09

## 结论

v0.5 进入 Beta 发布验证，功能范围冻结，不追加 F5 或新的大型模块。

这是一项“可以开始发布验证”的结论，不等同于正式发布许可。Linux、Windows 和
macOS 的构建、干净安装、旧数据升级、进程退出及 ASR smoke test 仍必须通过
[`release-checklist.md`](release-checklist.md)，才能创建版本标签。

## F1–F3 验收复核

| 里程碑 | 复核结果 | 主要证据 |
| --- | --- | --- |
| F1 显式多选与批量整理 | 通过 | 选择上限为 500；前端使用 ID 集合并通过单次 API 提交；后端事务、重复关联、部分无效 ID 和操作确认均有集成/Playwright 覆盖。 |
| F2 Transcript 保真修订与搜索上下文 | 通过 | 逐段编辑保留时间轴，同一事务更新 `full_text` 与 FTS；覆盖冲突、回滚、运行中 ASR 禁止编辑、导出和搜索跳转。 |
| F3 播放队列与会话连续性 | 通过 | 使用带版本的本地会话保存 ID、当前项和顺序；恢复时由后端过滤 deleted、missing、disabled root 和重复项；键盘、拖拽、停止及清空语义均有测试。 |

## 高频缺陷与性能

- Whisper 运行时已从默认安装包拆为可选 companion。主 backend、组件运行时和模型
  缓存拥有独立生命周期，运行中的本地转写可以通过终止 companion 进程取消。
- F4 发现批量整理会逐条查询最多 500 个音频 ID，已改为一次有界 `IN` 查询，避免
  规模增大时产生 N+1 查询。
- 新增 500 条收藏操作回归测试；在当前临时 SQLite 测试环境中，该 API 测试调用约
  0.15 秒。这个数字只用于发现明显回退，不作为跨设备性能承诺。
- 批量标签操作仍需为受影响音频重建 FTS。请求规模被限制为 500，此路径可进入
  Beta；更大媒体库的批量索引 profiling 留到稳定版前继续观察。

目前没有已知 P0/P1 高频缺陷需要新增功能里程碑。FastAPI `on_event` 弃用警告属于
后续维护项，不影响当前行为。

## 数据库与用户数据

- F1–F4 没有新增数据库表、字段或迁移，schema 版本保持为 6。
- F1 复用现有标签、Playlist 和收藏关系；F2 复用 Transcript/segment/FTS；F3 会话
  保存在浏览器/Tauri WebView 的本地存储中。
- Whisper 方案只新增 `components/` 和 `models/` 用户数据目录，不修改数据库。
- 现有迁移会在变更旧库前创建经过 `PRAGMA quick_check` 验证的备份；备份失败会停止
  迁移，较新 schema 也会拒绝由旧应用修改。Beta 阶段仍需用真实旧版数据副本验证。

## 安装包体积

Linux x64 本地构建的观测值：

| 产物 | 大小 |
| --- | ---: |
| lite backend sidecar | 约 24 MB |
| DEB / RPM 安装包 | 各约 28 MB |
| browser-lite 单文件程序 / ZIP | 各约 24 MB |
| Whisper companion 可执行文件 | 约 124 MB |
| Whisper companion ZIP | 约 123 MB |

模型权重不包含在上述产物中，首次本地转写时下载到
`~/.local_audio_library/models/faster-whisper/`。这使未使用本地 Whisper 的用户不再
承担约百 MB 的运行时体积；需要本地转写的用户只下载一次对应平台组件。

## Beta 验证门槛与风险

以下项目不要求追加功能里程碑，但都是发布阻塞项：

1. GitHub Actions 生成 Linux、Windows、macOS 的 Tauri bundle、browser-lite、
   companion ZIP 和汇总 manifest，并核对版本、目标平台与 SHA-256。
2. 三个平台完成干净安装、升级、卸载、动态端口和 backend/companion 退出测试。
3. 使用 Release manifest 安装 companion，完成一次真实模型下载、本地转写、取消、
   移除和重装；确认模型缓存保留。
4. 使用旧版数据库副本完成升级和备份恢复抽查。
5. Linux AppImage 需在网络可用的构建环境重新验证；本地 DEB/RPM 已生成，AppImage
   验证曾因 Tauri `linuxdeploy` 下载未完成而中止。

如果上述验证发现跨平台阻塞缺陷，只修复发布阻塞问题并复跑清单，不扩大 v0.5 范围。
