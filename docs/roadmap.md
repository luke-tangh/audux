# Local Audio Library 功能路线图

## 当前策略

v0.5 的功能范围已经冻结并进入 Beta 发布验证。`v0.5.0-beta.1` 版本字符串继续作为
内部候选标识，只有三平台构建和人工 release checklist 全部通过后才创建实际版本标签。

路线排序遵循以下原则：

1. 先缩短高频整理、检索和播放流程。
2. 优先完善已有能力，不立即引入新的模型或存储基础设施。
3. 涉及批量写入、Transcript 和备份的功能必须先定义事务与恢复语义。
4. 每个里程碑同时交付 API、前端、回归测试和文档，不积累跨层欠账。

## v0.5：核心工作流完善

### F1：显式多选与批量整理（已完成）

目标：让用户可以选择明确的一组音频进行整理，不再只能逐条操作或对整个筛选结果
创建 AI / ASR 任务。

范围：

- 音频列表进入多选模式，支持单选、全选当前页和清空选择。
- 对选中音频批量添加 / 移除标签。
- 对选中音频批量加入 Playlist。
- 对选中音频批量设为收藏 / 取消收藏。
- 批量操作确认框显示目标数量、跳过数量和影响范围。
- 后端提供批量整理 API；相关写入使用明确事务，返回逐项错误和汇总结果。
- 选择状态在筛选、切换视图或删除条目时有明确且可预测的清理规则。

验收门槛：

- 500 条选择规模下 UI 保持可操作，不为每条记录串行刷新页面。
- 重复添加标签或 Playlist 不产生重复关联。
- 部分无效 ID 不影响有效条目的结果，并向用户显示准确汇总。
- 后端 API 集成测试和前端 Playwright 行为测试覆盖主要成功、部分失败和取消流程。

暂不包含：批量删除音频、批量修改文件路径、跨全部搜索结果的隐式全选。

### F2：Transcript 保真修订与搜索上下文（已完成）

目标：修订文字时尽量保留可用时间轴，并让搜索结果提供足够上下文。

范围：

- 支持逐段修改 Transcript 文本，保留原有起止时间。
- 保存逐段修订时自动重建 `full_text` 和 FTS 索引。
- 保留现有全文修订作为明确的“替换全文并清除分段”高级操作。
- Transcript 搜索命中展示相邻上下文，并可从命中位置跳转播放。
- 编辑过程中提供未保存状态、取消和冲突提示。

验收门槛：

- 逐段修订不会改变未编辑分段的时间戳或顺序。
- Transcript、导出文件、搜索索引在一次事务后保持一致。
- ASR 正在运行时禁止编辑；过期内容写入不会静默覆盖新结果。
- 后端覆盖事务回滚和索引同步，前端覆盖编辑、取消和冲突流程。

暂不包含：手工修改时间戳、自动重新对齐、富文本和多人协作。

### F3：播放队列与会话连续性（已完成）

目标：将播放队列从临时页面状态提升为可恢复的本地播放会话。

范围：

- 从音频列表和详情页提供“下一首播放”和“加入队列”。
- 持久化队列音频 ID、当前项和顺序；应用重启后恢复。
- 恢复时跳过已删除或 missing 的条目，并给出非阻塞提示。
- 保持现有播放位置、倍速和音量恢复行为。
- 明确“清空队列”和“停止播放”的区别。

验收门槛：

- 正常关闭和异常重启后均可恢复合法队列顺序。
- 删除当前项、移除媒体库目录或禁用目录后不会留下无效播放索引。
- 键盘排序、拖拽排序和恢复逻辑拥有一致的回归测试。

### F4：v0.5 收口评估（已完成）

完成 F1–F3 后再进行一次范围评审：

- 修复真实使用中发现的高频缺陷，不追加大型新模块。
- 评估数据库迁移、性能和安装包体积变化。
- 决定进入 Beta 发布验证，还是追加一个明确、限时的功能里程碑。
- 只有决定发布后，才执行三平台构建和人工 release checklist。

评估结论：进入 Beta 发布验证，不追加 F5；只修复验证中发现的发布阻塞缺陷。数据库、
性能、安装包体积和剩余发布门槛见 [`v0.5-f4-evaluation.md`](v0.5-f4-evaluation.md)。

## v0.6：组织能力与数据可恢复性

- 保存筛选条件和排序方式，形成可复用视图。
- 智能 Playlist：基于标签、收藏、Transcript 状态和媒体库目录动态聚合。
- 手动创建、列出和校验数据库备份。
- 提供恢复预检、冲突说明和需要重启时的安全切换流程。
- Transcript 自动章节、章节导航和可选 AI 章节摘要。

## v0.7：语义检索

- 本地 embedding 模型和可替换的向量存储边界。
- metadata、标签与 Transcript 的混合检索。
- 明确索引重建、模型切换和删除数据时的同步语义。

## v0.8：基于 Transcript 的本地问答

- 按 Playlist、标签、媒体库目录和选择集限定问答范围。
- 回答必须引用 Transcript 时间戳并可跳转播放。
- 默认使用本地模型；远程 endpoint 继续采用显式授权和隐私提示。

## v1.0：稳定桌面版本

- 完成跨平台安装、升级、卸载和后端生命周期验证。
- 完整备份、恢复和迁移体验。
- 插件式模型接口与更完整的隐私模式。
- 建立兼容性承诺、迁移策略和稳定发布节奏。
